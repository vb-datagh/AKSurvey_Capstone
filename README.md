# Exploration and Analysis: 2025 Filipinx Survey

For my final capstone project in the General Assembly (GA) Data Analytics Fellowship, I conducted data exploration and analysis of the 2025 Filipinx Survey administered by the Amado Khaya Institute. I used Microsoft Excel for data cleaning, editing, and formatting, followed by Jupyter Notebook for further exploration and analysis.

The notebook uses Python libraries, including Pandas for data manipulation and Matplotlib and Plotly for data visualization.

View the **[Qualitative Coding Schema](https://vtech.neocities.org/qcs-filipinxsurvey)** for additional context on the survey's qualitative analysis framework.

# Executive Summary

Data cleaning and preparation were essential to ensuring the integrity and reliability of the analysis. This process involved reviewing data columns, addressing errors and null values, standardizing terminology and keys, and carefully selecting and aggregating survey responses to support meaningful analysis.
